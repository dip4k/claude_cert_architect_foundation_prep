# Claude Certified Architect – Foundations Certification Navigator

## Exam Overview
- **Passing Score**: 720 / 1000 (scaled score)
- **Time Limit**: 120 minutes | **Questions**: 60 multiple choice
- **Format**: 4 realistic scenarios drawn at random from 6 production contexts.

## 5 Content Domains & Weightings

| Domain | Title | Weight | Scope & Task Statements |
|---|---|---|---|
| **Domain 1** | Agentic Architecture & Orchestration | **27%** | Loops (`stop_reason`), subagents, SDK hooks, session state (TS 1.1–1.7) |
| **Domain 2** | Tool Design & MCP Integration | **18%** | Interfaces, structured MCP errors, tool choice, least privilege (TS 2.1–2.5) |
| **Domain 3** | Claude Code Configuration & Workflows | **20%** | CLAUDE.md hierarchy, path rules, plan mode, headless CI/CD (TS 3.1–3.6) |
| **Domain 4** | Prompt Engineering & Structured Output | **20%** | Tool Use schemas, nullable fields, validation loops, Batches API (TS 4.1–4.6) |
| **Domain 5** | Context Management & Reliability | **15%** | Persistent case facts, tool trimming, escalation, provenance (TS 5.1–5.6) |
